## 🧩 **Arquitectura del Sistema**

## 🔍 **Visión por Computadora (YOLOv8 + NCNN)**

### ✨ Características principales
- Modelo **YOLOv8** entrenado con dataset propio  
- Conversión a **NCNN** para rendimiento en Raspberry Pi  
- Inferencia en tiempo real **5–6 FPS**  
- Clases detectadas:  
  - 🟥 **PARE**  
  - 🟢 **Semáforo verde**

---

## 🛞 **Control y Movimiento (PID Avanzado)**

- Lectura de línea mediante sensores IR  
- Error calculado por **promedio ponderado**  
- PID ajustado manualmente para curvas exigentes  
- Estabilidad incluso con iluminación variable  
- Respuesta rápida para entornos competitivos  

---

## 🛠️ **Tecnologías Utilizadas**

### 🔧 **Hardware**
- Raspberry Pi 4 (8GB)  
- Arduino Uno  
- Sensores IR  
- Motores DC + Driver  
- Cámara Raspberry Pi  

### 💻 **Software**
- Python  
- YOLOv8 (Ultralytics)  
- NCNN  
- OpenCV  
- C++  
- Arduino IDE  

---

## 🚀 **Desafíos Técnicos Resueltos**

- Optimización de YOLOv8 para Raspberry Pi sin GPU  
- Reducción de latencia manteniendo precisión  
- Sincronización robusta entre visión y control  
- Tuning fino del PID para máxima estabilidad  
- Diseño competitivo bajo restricciones de hardware
